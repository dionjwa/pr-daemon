In short

    
Your project needs two commands: start this branch's stack and print its URL,
      and stop it and delete its data. A third, a check that must pass before a PR opens, is optional.
      They can be any shell command — npm, docker compose, make,
      a script — run with bash -lc from the branch's worktree. The
      just pr-daemon-up / -down / -check defaults are only a convention;
      set up, down and check per repo in
      Config to whatever your project already has.
